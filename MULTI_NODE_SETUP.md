# Настройка мульти-нод и мульти-инстансов Pterodactyl

## Что было изменено

1. **Улучшена работа с переменными яиц (eggs)** - теперь система автоматически получает все требуемые переменные из Pterodactyl API и заполняет их значениями по умолчанию
2. **Добавлена поддержка мульти-нод** - можно указать список нод для развёртывания серверов
3. **Добавлена поддержка мульти-инстансов Pterodactyl** - можно подключить несколько панелей Pterodactyl

## Настройка мульти-нод

### Вариант 1: Через базу данных

В таблице `plans` есть поле `node_ids` (JSON массив):

```sql
UPDATE plans SET node_ids = '["1", "2", "3"]' WHERE id = 1;
```

Это заставит систему выбирать случайную ноду из списка при создании сервера.

### Вариант 2: Автоматический выбор

Если `node_ids` не указан, система автоматически выберет наименее загруженную ноду.

## Настройка мульти-инстансов Pterodactyl

### Шаг 1: Добавьте настройки инстансов

В таблице `settings` добавьте настройки для каждого инстанса:

```sql
-- Основной инстанс (используется по умолчанию)
INSERT INTO settings (`key`, value, `group`) VALUES
  ('ptero_url', 'https://panel1.example.com', 'pterodactyl'),
  ('ptero_api_key', 'ptla_xxx1', 'pterodactyl');

-- Дополнительный инстанс #1
INSERT INTO settings (`key`, value, `group`) VALUES
  ('ptero_url_1', 'https://panel2.example.com', 'pterodactyl'),
  ('ptero_api_key_1', 'ptla_xxx2', 'pterodactyl');

-- Дополнительный инстанс #2
INSERT INTO settings (`key`, value, `group`) VALUES
  ('ptero_url_2', 'https://panel3.example.com', 'pterodactyl'),
  ('ptero_api_key_2', 'ptla_xxx3', 'pterodactyl');
```

### Шаг 2: Привяжите планы к инстансам

В таблице `plans` укажите `ptero_instance_id` для каждого плана:

```sql
-- План использует основной инстанс (по умолчанию)
UPDATE plans SET ptero_instance_id = NULL WHERE id = 1;

-- План использует инстанс #1
UPDATE plans SET ptero_instance_id = '1' WHERE id = 2;

-- План использует инстанс #2
UPDATE plans SET ptero_instance_id = '2' WHERE id = 3;
```

## Как это работает

1. При создании сервера система:
   - Получает `ptero_instance_id` из плана
   - Создаёт API клиент для соответствующей панели Pterodactyl
   - Получает `node_ids` из плана (если указано)
   - Выбирает ноду из списка или автоматически наименее загруженную
   - Получает переменные яйца из Pterodactyl API
   - Заполняет переменные значениями по умолчанию
   - Создаёт сервер

2. Переменные окружения:
   - Система получает все переменные из яйца через API
   - Для каждой переменной определяется значение по умолчанию на основе имени
   - Например: `BATTLE_EYE` → `"0"`, `SERVER_MAP` → `"TheIsland"`, и т.д.

## Примеры значений по умолчанию

| Тип переменной | Пример имени | Значение |
|---------------|--------------|----------|
| Battle Eye | `BATTLE_EYE` | `0` |
| Карта | `SERVER_MAP` | `TheIsland` |
| Порт | любой с `PORT` | `25565` |
| Версия | любой с `VERSION` | `latest` |
| Файл | любой с `FILE` или `JAR` | `server.jar` |
| Пароль | любой с `PASSWORD` | `""` |
| Java | любой с `JAVA` | `21` |
| Python | любой с `PYTHON` | `3.13` |

## API функции

Новые экспортируемые функции в `create-server.js`:

- `getAllNodes(pteroInstanceId)` - получить список всех нод
- `getAllEggs(pteroInstanceId)` - получить список всех яиц
- `clearClientCache()` - очистить кэш API клиентов
